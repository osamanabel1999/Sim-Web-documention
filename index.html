MSFS Connection Guide

A clean, step-by-step guide to connecting the SimulatorStation mobile app with Microsoft Flight Simulator on your PC.

Before you begin

  • Have Microsoft Flight Simulator running on your PC.
  • Keep your mobile device and PC on the same Wi-Fi network.
  • If you use SimBrief, IVAO, or VATSIM, have your relevant ID ready.
Step 1

Download the Bridge File

Download the SimulatorStation Bridge ZIP file to your Windows PC. Extract the downloaded ZIP folder before continuing.

DOWNLOAD BRIDGE FILE

After downloading: Open the ZIP file → extract it to a convenient location on your PC → open the extracted folder.

The file you need to run is: SimulatorStation_Bridge.v1.exe
Step 2

Run the Bridge Server

Open the extracted folder and double-click SimulatorStation_Bridge.v1.exe to start the bridge server.

  • 01 Open the extracted folder Locate the Bridge server files.
  • 02 Run SimulatorStation_Bridge.v1.exe Double-click the executable.
  • 03 Keep the black command window open Leave it running in the background while you fly.
Important: The bridge server must remain open in the background to maintain communication between MSFS and the mobile app.

Next, make sure your phone/tablet and the PC are connected to the same Wi-Fi network.
Step 3

Connect & Verify

Open the Simulator Station app on your device. Once the app detects the bridge server running on your PC, the red "Disconnected" banner at the top of the screen will automatically turn green and display "Connected".
